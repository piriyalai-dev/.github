# piriyalai-dev

Student-led open-source organization maintaining software, web services, and hardware projects for the Phiriyalai Phrae School community.

กลุ่มพัฒนาซอฟต์แวร์และโครงงานโอเพนซอร์สโดยนักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่ สำหรับรวบรวมและดูแลระบบที่ใช้งานจริงภายในโรงเรียนและชมรม

## Repositories

| Project | Description | Stack | Status |
| :--- | :--- | :--- | :--- |
| [`pirivoice`](https://github.com/piriyalai-dev/pirivoice) | Student feedback and issue portal with tiered escalation. | FastAPI, Vue, PostgreSQL, Docker Swarm, Traefik | Active |
| [`piriyalai-green-cheer-stand`](https://github.com/piriyalai-dev/piriyalai-green-cheer-stand) | Data-driven cheer-stand web app with song timelines, seat search, and printable badges. | Web | Archived / Event |

## Contributing

Bug reports, feature requests, and pull requests from students, alumni, and external contributors are welcome.

- **Issues:** Open an issue inside the relevant repository with reproduction steps or a clear problem statement.
- **Pull Requests:** Fork the repository, work on a feature branch, and keep commits scoped to a single change.
- **Security:** Do not open public issues for security vulnerabilities or exposed credentials. Contact a maintainer directly instead.
